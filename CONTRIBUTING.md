# Contributing

The `stack` repo is the **manifesto + bill of materials** for the openagentik ecosystem. It's content-heavy, code-light. Most contributions are documentation, framing, or BOM updates.

## What we accept

- Typo + grammar fixes (any language).
- New translations (FR is shipped; ES, DE, PT, IT, JA welcome).
- BOM updates when a new layer ships (e.g., a new engine implementation).
- Diagram improvements (ASCII or SVG).
- Persona docs (`docs/for-*.md`).
- FAQ entries.

## What we don't accept here

- Spec changes — those live in [agencies-sh/spec](https://github.com/agencies-sh/spec).
- New agency packages — those live in [openagentik/companies](https://github.com/openagentik/companies).
- Code/runtime changes — those live in their respective repos.

## Translation guidelines

1. Translate `README.md` → `README.<lang>.md` (e.g., `README.es.md`).
2. Keep the structure 1:1 with the English source.
3. Add the language link at the top of all sibling READMEs.
4. Don't translate code, file paths, or repo URLs.
